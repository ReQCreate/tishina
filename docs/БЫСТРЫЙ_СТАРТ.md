# Быстрый старт

«Тишина Lite» — обработчик микрофона для Windows: шумодав, гейт, эквалайзер, компрессор и лимитер. Приложение обрабатывает звук и отдаёт его в виртуальный кабель, который выбирают OBS, Discord, Zoom, браузер и игры.

## 1. Установите «Тишину»

1. Откройте страницу релизов: <https://github.com/ReQCreate/tishina/releases/latest>.
2. Скачайте `TishinaSetup.exe`.
3. При желании сверьте SHA-256 с файлом `SHA256SUMS.txt` из того же релиза.
4. Запустите установщик.
5. Windows SmartScreen может предупредить, потому что файл не подписан кодом. Если файл скачан из официального релиза, нажмите «Подробнее» → «Выполнить всё равно».
6. Установщик поставит программу в профиль пользователя, без прав администратора.

После установки появятся ярлыки в меню «Пуск» и на рабочем столе.

## 2. Установите VB-Cable

VB-Cable — отдельный виртуальный аудиокабель. Он не входит в установщик.

1. Откройте <https://vb-audio.com/Cable/>.
2. Скачайте `VBCABLE_Driver_Pack...`.
3. Распакуйте архив.
4. Запустите `VBCable_Setup_x64.exe` **от имени администратора**.
5. Установите драйвер и перезагрузите компьютер, если установщик попросит.

После установки в системе появятся устройства `CABLE Input` и `CABLE Output`.

## 3. Настройте «Тишину»

1. Запустите «Тишину».
2. Нажмите **«Обновить»**.
3. **Микрофон** — выберите свой физический микрофон. Лучше вариант с `WASAPI` и `48000 Hz`.
4. **Выход** — выберите `CABLE Input (VB-Audio Virtual Cable)`.
5. Выберите пресет **Stream** или **Chat**.
6. Нажмите **«Старт»**. Статус должен стать **РАБОТАЕТ**.
7. Скажите что-нибудь — индикаторы «Вход» и «Выход» должны двигаться.

## 4. Настройте OBS или Discord

### OBS

1. Добавьте источник **Audio Input Capture**.
2. Выберите `CABLE Output (VB-Audio Virtual Cable)`.
3. В настройках OBS → Аудио поставьте `48 kHz`.
4. Уберите или замьютьте прямой микрофон, если он добавлен вторым источником.

### Discord

Настройки → Голос и видео:

- **Устройство ввода:** `CABLE Output (VB-Audio Virtual Cable)`.
- **Шумоподавление:** выключить.
- **Эхоподавление:** выключить.
- **Автоматическая регулировка усиления:** выключить.

## 5. Проверьте маршрут

Правильно:

```text
Микрофон → Тишина → CABLE Input → CABLE Output → OBS / Discord / Zoom
```

Неправильно:

- выбирать `CABLE Input` как микрофон в OBS/Discord;
- выбирать `CABLE Output` как выход в «Тишине».

## Горячие клавиши

- `Ctrl+Alt+M` — Mute.
- `Ctrl+Alt+B` — обход обработки.

Клавиши работают, когда окно «Тишины» активно. Закрытие окна сворачивает программу в трей; обработка продолжается. Выход — через меню иконки в трее.

## Если что-то не работает

- **Нет `CABLE Input`** — проверьте установку VB-Cable, нажмите «Обновить», перезагрузите компьютер.
- **Не двигается «Вход»** — проверьте микрофон, доступ Windows к микрофону и закройте программы, которые монопольно заняли устройство.
- **В OBS/Discord тишина** — проверьте маршрут: выход в «Тишине» — `CABLE Input`, микрофон в приложении — `CABLE Output`.
- **Слышно эхо** — уберите прямой микрофон из OBS/Discord и отключите встроенные шумодавы приложения.
- **Гейт режет слова** — опустите порог гейта до `-48…-50 dB`. Если пролезает шум — поднимите до `-36…-38 dB`.
