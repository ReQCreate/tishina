Тишина Lite 0.1.0

Это персональный обработчик микрофона для OBS, Discord, Zoom, игр и браузера.

ВАЖНО: VB-Cable НЕ входит в этот установщик.

После установки:
1. Запустите «Тишину».
2. Нажмите кнопку «?» в правом верхнем углу — там пошаговая инструкция.
3. Установите VB-Cable с официального сайта: https://vb-audio.com/Cable/
4. В «Тишине» выберите свой микрофон и выход CABLE Input.
5. В OBS/Discord/Zoom выберите микрофон CABLE Output.

Полная инструкция также лежит в папке docs установленной программы.

Маршрут:
  Тишина -> CABLE Input -> CABLE Output -> OBS/Discord/Zoom

Если CABLE Input уже есть в списке устройств, установка кабеля не нужна.
